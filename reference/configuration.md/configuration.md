# Configuration reference



This page documents the small set of settings used by the example site.



## Site identity



| Field | Purpose |

| --- | --- |

| `name` | The display name shown in the documentation header. |

| `theme` | The visual theme used by Docs7. |

| `colors` | Primary, light, and dark brand colors. |



## Navigation



The `navigation.groups` collection defines the sidebar. Every page listed there should point to a Markdown or MDX file without its extension.



## Maintenance checklist



Before publishing a change, confirm that links resolve, headings are descriptive, and the navigation includes any new public page.
